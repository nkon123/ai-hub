## Design Context

### Users

사내 폐쇄망 PC에서 로컬 AI를 사용하는 일반 업무 사용자와 운영자. 사용자는 기술 구성을 관리하는 것보다 빠르게 새 대화를 시작하고, 필요한 경우에만 보유 Knowledge나 허브 조회를 선택해 근거 있는 답변을 얻고자 한다.

### Brand Personality

차분함, 신뢰감, 간결함. 장애와 보안 경계는 숨기지 않되 정상적인 대화 흐름을 방해하지 않고, 기술 용어보다 사용자가 하려는 일을 먼저 보여준다.

### Aesthetic Direction

밝은 업무용 인터페이스를 유지하는 정제된 미니멀 방향. 기존 블루 브랜드 색상과 Pretendard/Noto Sans KR 계열을 사용하며, 대화 목록과 작성 영역의 위계를 분명히 한다. 긴 상시 설명 대신 짧은 라벨과 접근 가능한 아이콘 툴팁으로 점진적으로 정보를 공개한다. 장식적 그래디언트, 과도한 카드 중첩, 네온 기반 AI 이미지는 사용하지 않는다.

### Design Principles

1. 새 대화, 대화 전환, 모델 선택을 한눈에 찾을 수 있게 한다.
2. 기본 화면은 간결하게 유지하고 정책·보안 설명은 포커스와 호버에서 제공한다.
3. Knowledge와 허브 조회는 명시적인 사용자 선택으로 유지하며 기본값과 전송 경계를 바꾸지 않는다.
4. 오류와 복구 방법은 실제 영향 수준에 맞게 표시하고 정상 대화를 가리지 않는다.
5. 키보드 포커스, `aria-label`, 툴팁을 함께 제공해 아이콘만으로 의미가 사라지지 않게 한다.
