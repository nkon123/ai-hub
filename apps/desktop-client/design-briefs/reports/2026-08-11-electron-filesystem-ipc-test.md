# Electron 파일시스템 IPC 테스트 보고

## 받은 지시

> 파일 시스템 ipc까지 테스트 하고 싶은거야

## 수행 내용

- Electron 43.3.0 공식 런타임을 설치하고 실행 파일 버전을 확인했다.
- 기존 5174 브라우저 프리뷰를 유지한 채 5173 Vite 서버와 Electron을 분리 실행했다.
- Electron 렌더러의 `window.desktop` preload 브리지에 실제로 연결했다.
- 설치 루트, Desktop 설정, 디스크 정보, 시스템 정보, 설치 자산 및 대화 목록 IPC를 호출했다.
- 임시 대화를 생성하고 턴을 추가한 뒤 다시 조회하고 삭제해 파일 쓰기·읽기·삭제 왕복을 검증했다.
- 진단용 임시 대화는 삭제되어 남지 않았다.

## 결과

- Electron 43.3.0 실행: 통과
- preload 브리지: 사용 가능, 38개 메서드 노출
- 파일시스템 루트: `~/Library/Application Support/desktop-client`
- 설정·디스크·시스템 정보 조회: 통과
- 설치 자산 목록 조회: 통과
- 대화 생성·턴 추가·조회·삭제: 전부 통과
- 기존 설치 자산과 대화는 각각 0개였다.

## 추가 발견

- `pnpm dev`는 Vite와 Electron을 동시에 시작해, 최초 의존성 최적화 시 Electron이 5173 준비보다 먼저 접근하여 `ERR_CONNECTION_REFUSED`가 한 번 발생할 수 있다.
- 이번 검증은 Vite가 준비된 후 Electron을 별도로 실행해 이 시작 순서 문제를 피했다.
- Mac 화면이 잠겨 있어 파일 선택 대화상자 같은 네이티브 UI 상호작용은 자동 확인하지 못했다.
